CPI:Nextについて

CPI:Next は、beatmania IIDX SPの難易度を譜面データから分析し、「次にどの譜面を遊ぶか」を考えるための非公式ファンサイトです。

主にSP☆8〜☆12を対象として、譜面ごとの難易度指標 Pred、譜面の特徴 Feature、クリアランプに基づく個人向けの難易度補正やリコメンドなどを提供しています。

公式レベルだけでは区別しにくい同じ☆内での難易度差や、EASY・NORMAL・HARDで変わる難しさ、プレイヤーごとの得意・不得意を、選曲の参考になる形で可視化することを目的としています。

Predについて

Pred は、譜面情報とゲージシミュレーションなどから推定した、CPI:Next独自の難易度指標です。

各譜面について、イージー・ノマゲ・ハード難易度を表示しています。

公式レベルより細かい値を計算していますが、絶対的な難易度を保証するものではありません。プレースタイル、オプション、得意・不得意などによって体感難易度は変化します。次に挑戦する譜面を探すための一つの基準としてご利用ください。

Featureについて

一部の譜面には、配置の特徴を表す Feature を表示しています。

現在は、BPM変化 / チャージノート / ラスト難 / 皿複合 / 単鍵ラッシュ / 同時押し / 物量 / 連皿 / 連打を扱っています。これらは、同程度のPredの譜面と比較して、その特徴を強く持つ譜面に表示しています。

+ や ++ が付いているFeatureは、上記の傾向がより強いことを示します。例えば「連皿++」は、すべての譜面の中で絶対的に連皿が最難関という意味ではなく、同程度の難易度帯の譜面と比べて連皿傾向が特に強いことを表します。

自分向けのPredとリコメンド

クリアランプを登録すると、CPI:Nextはそのデータからプレイヤーの適正クリア難易度、得意譜面傾向を推定します。

マイページでは現在の適正Predを確認できます。

マイターゲットでは、譜面のFeatureと過去のクリア状況をもとに、得意・不得意を反映した 補正Pred とクリア見込みを推定します。

リコメンドは、デフォルトではクリア確率が40%～60%となる、簡単すぎず難しすぎない挑戦曲を表示します。これは目的に応じて設定から変更することが可能です。

今日の10曲

今日の10曲では、その日に狙う譜面を最大10曲まで選び、EASY・CLEAR・HARDなどの目標を決めて挑戦できます。

マイターゲットのリコメンドや手動メモから選曲することもでき、プレイ後にクリアランプを更新すると達成状況が反映されます。

「何をやるか迷う」「やる曲を決めておきたい」というときの、プレイリストとして使うことを想定しています。

段位認定ラボ

段位認定ラボでは、段位認定の課題曲をPredやゲージシミュレーションから分析しています。

単純な課題曲の平均難易度だけではなく、段位ゲージを考慮して、各STAGEまで到達するためにどの程度の地力が必要と推定されるかといった分析も行っています。

これらはシミュレーションによる推定値であり、実際の合格率や合格を保証するものではありません。段位の構成を考えるための参考値としてご覧ください。

予測の限界について

CPI:Nextの難易度推定は、すべてのプレイヤーの体感を完全に再現するものではありません。

特に、

  • スクラッチやCN、ソフランなど個人差の大きい譜面
  • RANDOMなどのオプションによって難易度が大きく変化する譜面
  • 特殊な配置を持ち、似た譜面が少ないケース

では、Predと実際の体感に大きな差が生じる場合があります。

また、新曲・新譜面など必要な譜面情報が十分に確認できていないものについては、Predを掲載していない場合があります。

譜面情報について

難易度推定のための譜面情報の一部について、TexTage（https://textage.cc/）様の情報を参考にさせていただいています。

また、☆12の難易度推定・検証の一部では、既存の CPI（https://cpi.makecir.com/）の情報も参考にしています。

データの保存について

クリアランプ、手動メモ、今日の10曲などのユーザーデータは、原則として利用しているブラウザ内に保存されます。

アカウント登録やログインは必要ありません。また、登録したクリアランプをCPI:Nextのサーバーへ保存する仕組みはありません。

ブラウザのデータ削除、端末変更、ブラウザ変更などによってデータが失われる可能性があります。必要に応じて設定ページからバックアップを取得してください。
